# Shared Chhath Music Library

Upload MP3 or M4A audio files to this folder using GitHub's **Add file → Upload files** interface.

Files will appear automatically in the Chhath Puja app's Shared Music Library after committing to the `main` branch. The app reads this folder from GitHub's public Contents API. Keep the repository public for visitors to load the library. Do not upload copyrighted music unless you have permission to distribute it.

GitHub limits files uploaded through its browser interface to 25 MiB per file; for larger files, use Git (with GitHub's 100 MiB per-file hard limit). This is intended for a small collection, not high-traffic streaming.
